# MOGGулятор3000 (MOGGulator3000)

> Кроссплатформенное приложение для распознавания математических выражений по фотографии, их вычисления и построения пошагового решения.

## 📌 О проекте

Студенты, школьники и преподаватели регулярно сталкиваются с необходимость быстро проверять и решать математические выражения. Ручной ввод длинных формул занимает время и часто приводит к ошибкам.

**MOGGулятор3000** решает эту проблему: пользователь загружает фотографию математического примера, приложение автоматически распознаёт текст с помощью OCR, вычисляет результат, показывает детальное пошаговое объяснение и сохраняет запись в историю.

Проект разработан в рамках учебной практики по модулю **ПМ.02 «Осуществление интеграции программных модулей»** (ГБПОУ НО «Новосибирский электромеханический колледж»).

---

## ✨ Функциональность (MVP)

1. **📷 Загрузка изображения**: Поддержка графических файлов популярных форматов (PNG, JPG, BMP).
2. **🔍 OCR-распознавание**: Предобработка снимка (OpenCV) и распознавание текста выражения (Tesseract OCR).
3. **🧮 Разбор и вычисление**: Синтаксический анализ и вычисление выражений с поддержкой операторов `+`, `-`, `*`, `/`, `^`, скобок и унарного минуса.
4. **📝 Пошаговое решение**: Генерация понятного текстового объяснения каждого этапа вычисления.
5. **📜 История операций**: Автоматическое сохранение истории вычислений в локальную БД SQLite.

## 🛠 Технологический стек

- **Язык программирования**: C++17
- **GUI-фреймворк**: Qt 6
- **Обработка изображений & OCR**: OpenCV, Tesseract OCR
- **База данных**: SQLite 3
- **Система сборки**: CMake (3.16+)
- **Тестирование**: GoogleTest (GTest)
- **CI/CD**: GitHub Actions
- **IDE / Среда**: Visual Studio Code / Windows
