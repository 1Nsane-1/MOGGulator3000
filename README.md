MOGGulator3000
Быстрый, надежный и точный консольный (CLI) C++ калькулятор. Программа вычисляет математические выражения любой вложенности, используя алгоритм сортировочной станции (Shunting-yard) и обратную польскую запись (RPN).

Возможности
Поддержка скобок и стандартных арифметических операций (+, -, \*, /).

Генерация подробного пошагового решения (StepGenerator).

Надежная обработка ошибок (деление на ноль, невалидный ввод) через иерархию исключений.

Стек технологий
Язык: C++17

Сборка: CMake

Тестирование: CTest (12 unit-тестов)

Быстрый старт
Bash

git clone https://github.com/ВАШ_ЛОГИН/MOGGulator3000.git
cd MOGGulator3000
mkdir build && cd build
cmake ..
cmake --build .
./MOGGulator3000
