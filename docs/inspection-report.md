## Найденные несоответствия

### NC-01: Магическое число при сравнении вещественных чисел
- **Файл:** `src/core/evaluator.cpp`, строка 18
- **Категория:** Магические числа
- **Описание:** Прямое использование литерала `1e-6` при проверке погрешности деления и вычислений.
- **Рекомендация:** Вынести значение в `constexpr double EPSILON = 1e-6;` в заголовочном файле.
- **Приоритет:** Средний
- **Статус:** Исправлено

### NC-02: Отсутствие Doxygen-документации у публичных методов
- **Файл:** `src/db/history_repository.h`, строки 14–18
- **Категория:** Комментарии
- **Описание:** Методы `save()` и `readAll()` не имеют описания параметров и выброса исключений.
- **Рекомендация:** Добавить Doxygen-комментарии (`///`).
- **Приоритет:** Низкий
- **Статус:** Исправлено

### NC-03: Некорректное именование переменной
- **Файл:** `src/db/history_repository.cpp`, строка 21
- **Категория:** Именование
- **Описание:** Использование имени `tmp_e` вместо осмысленного `entry` или `historyEntry`.
- **Рекомендация:** Переименовать переменную в `historyEntry`.
- **Приоритет:** Низкий
- **Статус:** Исправлено

### NC-04: Дублирование кода вспомогательной обрезки строк (Trim)
- **Файл:** `src/core/math_expression.cpp` и `src/core/expression_parser.cpp`
- **Категория:** Дублирование
- **Описание:** Лямбда-функция для удаления пробелов по краям строки продублирована в двух модулях.
- **Рекомендация:** Вынести функции `trim()` и `replaceAll()` в общий модуль `src/utils/string_utils.h`.
- **Приоритет:** Высокий
- **Статус:** Исправлено

### NC-05: Длинный метод парсинга выражения
- **Файл:** `src/core/expression_parser.cpp`, метод `parseToRPN`
- **Категория:** Структура кода
- **Описание:** Метод содержит 62 строки и совмещает токенизацию и обработку стека операторов.
- **Рекомендация:** Разбить метод на `tokenize()` и `convertToRPN()`.
- **Приоритет:** Высокий
- **Статус:** Исправлено

### NC-06: Жестко зашитый путь к файлу по умолчанию
- **Файл:** `src/db/history_repository.h`, строка 16
- **Категория:** Магические значения
- **Описание:** Строка `"data/history.txt"` передаётся как дефолтный аргумент метода без выноса в константу.
- **Рекомендация:** Вынести в `static constexpr const char* DEFAULT_HISTORY_PATH = "data/history.txt"`.
- **Приоритет:** Средний
- **Статус:** Не исправлено (Запланировано на следующий релиз)

### NC-07: Отсутствие проверки на предельные размеры входящей строки
- **Файл:** `src/core/math_expression.cpp`
- **Категория:** Обработка ошибок
- **Описание:** Длина входящего выражения не ограничена, что может вызвать переполнение при передаче мультигигабайтных строк.
- **Рекомендация:** Добавить проверку `MAX_EXPRESSION_LENGTH = 10000` в конструктор.
- **Приоритет:** Низкий
- **Статус:** Не исправлено (Запланировано на следующий релиз)

### NC-08: Неединообразные отступы в тестовом файле
- **Файл:** `tests/unit_tests.cpp`, строки 80–95
- **Категория:** Структура кода
- **Описание:** Смешение отступов в 2 и 4 пробела.
- **Рекомендация:** Привести к единому стандарту 4 пробела.
- **Приоритет:** Низкий
- **Статус:** Не исправлено (Запланировано на следующий релиз)
