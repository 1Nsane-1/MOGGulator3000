Руководство по установке
MOGGulator3000
Версия: 1.0

1. Требования
Компилятор C++: Поддержка стандарта C++17 (GCC 7+, Clang 5+, MSVC 19.14+).

Система сборки: CMake версии 3.15 или выше.

Система контроля версий: Git.

2. Установка и сборка
Клонируйте репозиторий проекта:
git clone [https://github.com/ВАШ_ЛОГИН/MOGGulator3000.git](https://github.com/ВАШ_ЛОГИН/MOGGulator3000.git)
cd MOGGulator3000

Создайте директорию для сборки и сгенерируйте файлы CMake:
mkdir build
cd build
cmake ..

Скомпилируйте проект:
cmake --build . --config Release

3. Настройка и тестирование
Проект не требует внешних конфигурационных файлов базы данных или сети. Для проверки корректности сборки запустите встроенные тесты:
ctest --output-on-failure
(Или напрямую запустите исполняемый файл ./unit_tests).

4. Развёртывание
Поскольку это CLI-утилита, развертывание заключается в копировании скомпилированного бинарного файла MOGGulator3000 (из папки build/) в любую директорию, добавленную в системный PATH (например, /usr/local/bin на Linux/macOS).

5. Решение проблем
Проблема: CMake Error: CMake was unable to find a build program...
Решение: Убедитесь, что у вас установлены инструменты сборки (Make/Ninja для Linux, Build Tools for Visual Studio для Windows).

Проблема: Ошибки компиляции, связанные со стандартом C++.
Решение: Убедитесь, что ваш компилятор поддерживает C++17. Попробуйте обновить GCC/Clang.
