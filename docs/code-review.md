### Замечания по ветке `feature/math-expression`

- **Автор кода:** Грузин Егор
- **Ревьюер:** Кондрашкин Григорий

1. **Файл `src/core/math_expression.h`**:
   - _Замечание:_ Метод `getNormalized()` не изменяет внутреннее состояние объекта, однако константный спецификатор отсутствует.
   - _Рекомендация:_ Добавить спецификатор `const` и атрибут `[[nodiscard]]`.
   - _Статус:_ Исправлено в коммите `7a1d2e3`.

2. **Файл `src/core/math_expression.cpp`**:
   - _Замечание:_ При нормализации строки заменяется только запятая `,` на точку `.`, но не обрабатывается знак двоеточия `:`.
   - _Рекомендация:_ Добавить строку `std::replace(m_normalized.begin(), m_normalized.end(), ':', '/');`.
   - _Статус:_ Исправлено в коммите `7a1d2e3`.

3. **Файл `docs/coding-standards.md`**:
   - _Замечание:_ В соглашениях об именовании не был явно указан префикс для приватных полей классов.
   - _Рекомендация:_ Прописать правило использования префикса `m_` (например, `m_expression`).
   - _Статус:_ Исправлено в коммите `8b2c4f1`.
