# Чек-лист ручного и консольного тестирования MOGGulator3000

## Дата: 30.09.2026
## Команда: MOGGulator Devs
## Тестировщик: Грузин Егор

## Функциональность (C++ CLI Core)
- [x] Корректность вычисления простых выражений (+, -, *, /).
- [x] Соблюдение приоритета операций и вложенных скобок.
- [x] Обработка унарного минуса (отрицательных чисел).
- [x] Нормализация строк: замена запятых на точки (2,5 -> 2.5) и двоеточий на деление (12:4 -> 12/4).
- [x] Формирование и вычисление пошагового отчёта решения.
- [x] Дозапись истории успешных вычислений в файл `data/history.txt`.
- [x] Стабильность главного CLI-цикла при вводе некорректных данных.

## Нефункциональность (Performance & Environment)
- [x] Время вычисления одиночного выражения < 1 мс.
- [x] Время вычисления сложного выражения со скобками < 5 мс.
- [x] Нагрузочный прогон 1000 математических операций < 50 мс.
- [x] Серийная запись 100 элементов истории < 100 мс.
- [x] Отсутствие утечек памяти при работе с `std::stack` и динамическими строками.

## Обработка ошибок и устойчивость (Exceptions)
- [x] Перехват прямого деления на ноль (`MathError`).
- [x] Перехват косвенного деления на ноль через скобки (`15/(5-5)` -> `MathError`).
- [x] Выбрасывание `ValidationError` при пустом вводе или пробелах.
- [x] Выбрасывание `ValidationError` при вводе букв или спецсимволов.
- [x] Выбрасывание `StorageError` при ошибке доступа к файлу истории.
- [x] Устойчивость к каскаду сменяющих друг друга ошибок разного типа.
