# Чек-лист ручного и консольного тестирования MOGGulator3000

## Дата: 29.09.2026
## Команда: MOGGulator Devs
## Тестировщик: Грузин Егор

## Функциональность (C++ CLI Core)
- [ ] Корректность вычисления простых выражений (+, -, *, /).
- [ ] Соблюдение приоритета операций и вложенных скобок.
- [ ] Обработка унарного минуса (отрицательных чисел).
- [ ] Нормализация строк: замена запятых на точки (2,5 -> 2.5) и двоеточий на деление (12:4 -> 12/4).
- [ ] Формирование и вычисление пошагового отчёта решения.
- [ ] Дозапись истории успешных вычислений в файл `data/history.txt`.
- [ ] Стабильность главного CLI-цикла при вводе некорректных данных.

## Нефункциональность (Performance & Environment)
- [ ] Время вычисления одиночного выражения < 1 мс.
- [ ] Время вычисления сложного выражения со скобками < 5 мс.
- [ ] Нагрузочный прогон 1000 математических операций < 50 мс.
- [ ] Серийная запись 100 элементов истории < 100 мс.
- [ ] Отсутствие утечек памяти при работе с `std::stack` и динамическими строками.

## Обработка ошибок и устойчивость (Exceptions)
- [ ] Перехват прямого деления на ноль (`MathError`).
- [ ] Перехват косвенного деления на ноль через скобки (`15/(5-5)` -> `MathError`).
- [ ] Выбрасывание `ValidationError` при пустом вводе или пробелах.
- [ ] Выбрасывание `ValidationError` при вводе букв или спецсимволов.
- [ ] Выбрасывание `StorageError` при ошибке доступа к файлу истории.
- [ ] Устойчивость к каскаду сменяющих друг друга ошибок разного типа.
