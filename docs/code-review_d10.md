**Проверяемая команда:** Команда №2 (Проект ParkBooking)
**Ревьюер:** 1Nsane-1 (Грузин Егор)

## Замечания по автоматизации и unit-тестам

1. **Отсутствие изолирующих хуков (beforeEach):**
   В тестах функции `createBooking` не очищается состояние `localStorage` перед каждым тестом. Это может вызывать взаимное влияние тестов друг на друга при изменении порядка их запуска.

2. **Недостаточное покрытие граничных значений:**
   В тестах `calcPrice` отсутствуют проверки на дробные значения часов и на передачу отрицательных аргументов. Рекомендуется добавить кейсы с граничными параметрами.

3. **Отсутствие шагов сборки в CI-воркфлоу:**
   В конфигурации GitHub Actions указан запуск тестов без предварительного шага установки зависимостей (`npm ci`). На чистом runner workflow падает с ошибкой missing modules.

4. **Информативность сообщений об ошибках:**
   В проверки `expect(...).toThrow()` стоит передавать конкретный текст ожидаемого исключения, чтобы не пропустить ложноположительное падение по другой причине.
