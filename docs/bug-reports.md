# Баг-репорты MOGGulator3000

## BR-01: Отсутствие автоматического создания папки data/ при сохранении истории
- **Связанный тест-кейс:** TC-13
- **Приоритет:** Критический
- **Шаги воспроизведения:**
  1. Удалить папку `data/` в корне проекта.
  2. Запустить `MOGGulator3000`.
  3. Вычислить выражение `"5 + 5"`.
- **Ожидаемый результат:** Создаётся папка `data/` и файл `data/history.txt`.
- **Фактический результат:** Выбрасывается `StorageError`, так как каталог не существует.
- **Причина:** `HistoryRepository::save()` не проверяет наличие целевой директории перед выполнением `std::ofstream`.
- **Решение:** Добавлен вызов `std::filesystem::create_directories(path.parent_path())` перед созданием потока записи.
- **Статус:** Исправлен (Закрыт)
- **Результат повторной проверки (30.09.2026):** Проведён повторный ручной прогон TC-13. Директория `data/` была предварительно удалена. После вычисления выражения `"5 + 5"` папка `data/` сформировалась автоматически, файл `data/history.txt` создался и содержит корректную запись `"5 + 5 = 10"`. Тест-кейс TC-13 повторно пройден (✅).
- **Исполнитель:** 1Nsane-1 (Грузин Егор)

## BR-02: Ошибка обработки унарного минуса при наличии пробелов
- **Связанный тест-кейс:** TC-20
- **Приоритет:** Высокий
- **Шаги воспроизведения:**
  1. Запустить `MOGGulator3000`.
  2. Ввести выражение `" - 5 + 10"`.
- **Ожидаемый результат:** `5`.
- **Фактический результат:** Выбрасывается `ValidationError` ("Некорректный синтаксис").
- **Причина:** Проверка унарного минуса `expr[i-1] == '('` выполнялась до полной очистки строки от пробелов.
- **Решение:** Выполнять удаление всех пробельных символов в `Evaluator::evaluate` до начала парсинга токенов.
- **Статус:** Исправлен (Закрыт)
- **Исполнитель:** Грузин Егор
