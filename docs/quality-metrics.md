## Таблица адаптации и применимости метрик для C++ CLI проекта

Так как `MOGGulator3000` является консольным C++ приложением, а не Web-сайтом, стандартные метрики из ТЗ сопоставлены с их CLI-эквивалентами:

| Исходная метрика ТЗ | CLI C++ Эквивалент | Обоснование и применимость |
|---------------------|---------------------|----------------------------|
| **Время загрузки (< 2 с)** | Время парсинга и вычисления выражения | В CLI отсутствует сетевая загрузка и DOM. Измеряется чистое время работы ядра через `std::chrono`. |
| **Размер бандла (< 500 KB)** | Размер скомпилированного бинарника | Вместо JS/CSS бандла измеряется размер исполняемого файла Release-сборки (`MOGGulator3000`). |
| **Ошибки в консоли (0)** | Предупреждения компилятора GCC/Clang | В C++ аналогией консольных ошибок являются warnings при сборке с флагами `-Wall -Wextra -Werror`. |
| **Адаптивность (320px+)** | Корректная обработка некорректного CLI-ввода | Консоль не имеет пиксельной сетки. Оценивается устойчивость приложения к невалидным символам и делению на 0. |
| **Клики до цели (≤ 4)** | Количество шагов/вводов для получения ответа | Пользователь получает результат за 1 ввод строки выражения в интерактивном CLI. |

## Выводы и рекомендации

### В норме
- Все 13 метрик (включая 5 адаптированных для CLI) находятся в зелёной зоне.
- Покрытие unit-тестами составляет 85% (цель ≥ 70%).

### Рекомендации
1. Добавить автоматический прогон `CTest` и проверку размера бинарного файла в GitHub Actions CI.
2. Расширить Doxygen-комментарии для приватных методов класса `Evaluator`.
